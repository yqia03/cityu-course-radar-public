# 外部课程评价维护

`data/external-reviews.json` 是只读的编辑精选快照；`data/external-review-provenance.json` 保存检索、核对和排除依据。首批核对日期为 2026-09-16；第二轮扩充核对日期为 2026-09-25。这不是实时爬虫，也不是全校热度调查。

## 收录流程

1. 找到公开原帖，实际打开并核对正文。汇总站只用于发现链接，不以搜索摘要代替原帖。不得绕过登录限制或验证码。
2. 对照官方目录确认 CityU Hong Kong 的课程代码和名称。只有简称、历史名称变更尚未核实、广告、单纯提问的条目留在排除记录中。
3. 用稳定 `sourceId` 标识原帖／具体评论，用 `id` 标识「来源 + 课程」。同一来源跨多课共享 `sourceId`，去重时移除 URL query/hash，不能用新的分享参数制造新来源。保存平台、公开作者名、原帖链接、原帖日期（没有就 `null`）、学期（未知就 `null`）、核对日期。原帖编辑日期在 `context` 中说明。
4. 将原始评分标签与星号完整照录。没有分数用空 `ratings`，没有明确量表上限用 `scale: null`。不要将最高观察值当作满分；不计算外部总分，不把“考试体验”解释为难度。学业 A、B+ 等只能存入 `reportedGrade`，不转换成评分。
5. 每门课写一句简短的三语摘要，保留重要的正反信息和适用背景，不转载全文或图片。所有摘要均标记为本站整理／翻译。第三方原作权利归原作者，本项目 MIT 许可不覆盖第三方原文。
6. 同一原帖可对应多门课；同一讨论串的不同回复可分别收录。主页“参考条数”只数课程参考记录，不声称是独立作者、所有评论或全校热门度。`externalCoverage.sources` 数原始发言 URL（并非作者数）。
7. 为每条新增记录补 provenance 的 `recordEvidence`（课程匹配、目录 URL、正文段落/回复/图片序号/时间点），并把受阻和搜索线索留在 `pendingVerification`，不能发布。先运行 `node --test tests/external-reviews.test.mjs` 检查稳定来源、日期、三语、累计摘要和去重，再运行 `npm test`、`npm run typecheck`，检查课程页三种语言以及原帖跳转，再按项目部署流程发布。不要改写匿名访客的 `reviews` 数据表。

## 更新与纠错

至少每学期人工重查已收录原帖，保留历史背景，不把旧学期的评价描述为当前教学事实。原帖失效、作者要求撤回、课程对应错误时，从公开 JSON 移除相应记录，并在 provenance 的 `excluded` 中记录原因；Git 历史保存变更。评分、日期和课程对应的修正必须再次读取原帖，而不是依赖自动翻译猜测。

小红书链接中的 `xsec_token` 来自公开课评指南的分享链接，不来自任何登录会话；只保留打开公开原帖所需的参数。参数可能失效，重新核对后更新。不要保存 cookie、登录令牌、私信或私人群聊内容。

## 首批覆盖限制

收录 15 门课、22 条课程参考，来源为 5 篇小红书笔记、4 条 Dcard 发言（3 个讨论串）及 1 页个人课程心得。6 条星评都来自同一位小红书作者，代表该作者体验，不能当作多人的平台均分。其余条目没有数值课程评分。

LIHKG、Reddit、Facebook 的本次公开检索未核实到可对应课程代码的具体评价；未补造条目。RegCourse 跳转至无关域名，CityU GE Guide 当时没有返回课评。CS5285 的历史标题差异，以及 Dcard 三门仅有简称的推荐，暂不发布。

发现小红书原帖时参考了 [CityU-CS-Guide](https://github.com/null1024-ws/CityU-CS-Guide)，每个已发布摘要最终均对应直接读取的原帖。

## 2026-09-25 扩充快照

当前为 **25 门课、39 条课程参考、15 个独立原帖/发言 URL**。相对首批新增 10 门课、17 条参考和 5 个来源，其中小红书 +11 条（3 篇新原帖）、Dcard +1 条回复、个人博客 +5 条（同一篇文章）。8 条带星评的参考仍全部来自同一位作者。全部旧记录保留原核验日，不声称已逐条重查旧来源。

本轮完成两轮检索，并保留最后两组无新增来源的补检；部分小红书候选因登录、暂不可浏览或超时未被发布。详细范围、平台/院系分布、原帖定位、排除与候选清单见 [扩充报告](external-reviews-expansion-2026-09-25.md) 和 [机器可读检索日志](external-reviews-search-2026-09-25.json)。不把本轮有限检索描述为全网穷尽。

新增来源域名须人工读取原始页面并更新测试中的允许列表；不能放宽为任意 URL。更正/移除时同时更新两个数据文件的数量与来源身份，保持唯一「`sourceId` + `courseCode`」。三语摘要由同一原帖派生时累计控制长度，不按语言或课程重复计算转载额度。没有扫描网页或重新抓取就不要更新 `checkedAt`。
